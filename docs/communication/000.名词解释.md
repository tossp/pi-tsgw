# 通信能力：名词解释

本专题仅规范 pi-tsgw 跨设备通信能力的用语。需求、架构、执行与状态分别见同目录 A00、B00、C00、000.TODO。

| 主叫法 | 定义与边界 | 易混淆概念 |
| --- | --- | --- |
| 包 | 安装与发布单位，此处为 pi-tsgw | 不等于单一扩展 |
| 扩展入口 | 包内由 Pi 单独加载、过滤的入口 | 不代表独立进程或权限沙箱 |
| 设备标识 | 为一个运行环境自动生成并持久保存的稳定标识，可显式覆盖 | 不是 hostname、IP、端口或认证凭据 |
| 项目目录 | 会话在所属设备上的 cwd | 不能单凭路径判断跨设备为同一项目 |
| 主会话 | 用户讨论及接收协作请求的 Pi 会话 | 不要求一台设备只有一个 |
| 接待会话 | 通信全局启用后，在近期窗口内自动接收入站协作的运行主会话 | 不要求逐会话开放，不是设备总管 Agent |
| 会话身份 | 设备标识与 Pi 原始会话 ID 的组合；文中“规范身份／规范会话身份”均指此组合 | 名称、端口、Git 分支不是身份 |
| 会话实例 | 当前进程中运行的 AgentSession 及扩展运行时 | 会话文件存在不代表实例存活 |
| 子代理 | 主代理通过宿主 Agent 工具委派的执行单元 | 不等于通信扩展直接创建的独立工作者 |
| Relaycast 原生消息桥 | 通过既有 Relaycast 的 REST／WebSocket 在 Pi 主会话间传递协作消息 | 首版传输路线，不是标准 A2A 端点 |
| 协作信封 | 本插件为关联请求、确认、状态和结果使用的有版本结构化消息体 | 不是 Relaycast 原生任务协议，不是标准 A2A 报文 |
| A2A | Agent2Agent 标准协议；本专题后续可选的互操作适配 | 不把任意 Agent 间 JSON 消息称为标准 A2A |
| 对端 | 已认证、可寻址的协作端点 | 展示的设备名不是授权凭据 |
| 协作上下文 | 本插件以 contextId 关联的一组交互 | 字段是首版协作约定，不宣称为标准 A2A；不等于完整聊天历史或 Pi 会话 ID |
| 协作任务 | 本插件以 taskId 标识的可追踪工作单元 | 一个主会话可处理多个任务；不是后端原生 Task |
| 中央消息服务 | 已部署的 Relaycast，提供认证、原生消息存储与实时分发 | 不自动具备本插件的目录过期、任务状态或会话恢复能力 |
| 中央网关 | 旧方案的路由泛称，首版统一使用中央消息服务 | 不再表示需要另部署标准 A2A 网关 |
| 会话公告 | 通过 Relaycast 专用发现频道元数据消息发布会话信息，由通信客户端形成目录视图 | 不是聊天正文或触发模型的群发消息；原始后端记录不等于当前有效目录 |
| 有效目录 | 按合格活动时间、活动版本及在线信息过滤后的会话发现视图 | 72 小时退出此视图，不承诺后端自动物理删除原始公告 |
| 反向通道 | 设备主动连接中央消息服务后接收入站消息 | 首版使用原生 WebSocket，不表示额外部署 A2A 网关 |
| 近期窗口 | 距最近真实消息更新不足 3 天（72 小时）的自动目录资格 | 不以心跳、文件 mtime 或页面打开续期，不等于在线状态 |
| 接待暂停 | 超出近期窗口后停止新请求与新补充输入；仍可在实例存活及保留期内查询原记录 | 不等于删除／取消任务；远端输入不能自行激活 |
| 在线状态版本 | 同一接待代次内递增的 presenceRevision，排序心跳与在线／忙碌／离线变化 | 与只随真实消息更新的 activityRevision 分开 |
| 任务状态版本 | 执行侧 taskId 记录拥有的 stateRevision，发起侧保存 remoteStateRevision 镜像 | 不与发起侧投递状态或目录版本比较 |
| 保活 | 阻止会话实例被普通空闲回收 | 不等于进程守护、开机恢复或任务重放 |
| 接收确认 | 请求已被本端可靠记录并分配任务标识 | 不等于主代理已处理或任务已完成 |
| 等待问题通知 | 执行侧进入 input_required 后发送的持久问题，标明当前等待轮次与状态版本 | 不是终态结果；查询可补齐但不重复唤醒 |
| 本地通知投递 | 发起端将已保存的问题／结果送入原会话的独立记录，以 notificationId 查证 | 网络 received 不证明模型已读取，injection_unknown 不代表远端任务失败 |
| 恢复索引 | 原 request／input 消息 ID 与任务／轮次的持久映射 | 独立于短期去重窗口，结果仍保留时不能提前清除 |
| 结果提交 | 主代理显式提交某个协作任务的结果 | 不从任意 assistant 最后一句话推断任务结束 |

术语表是本专题的命名基线。工具名、配置键、目录名在 C00 中均为拟定值，经过实现审批后才成为公共接口；不得把本文的概念定义作为接口已发布的依据。
