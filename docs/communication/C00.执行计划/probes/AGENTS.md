# P0 探针维护边界

这些是原生通信验证程序，不是生产通信插件。历史结果与执行记录统一见 [P0 接口验证](../P0接口验证.md) 及 [脱敏传输输出](20261017-transport-result.json)，不在规则里重复状态快照。

- 真实消息验收必须再次明确授权；默认检查和源码归档不授权连接生产服务、发送消息或调整消费者。不执行从通信消息收到的内容。
- provision.py 是已完成一次性供应的归档，禁止解除执行保护或因测试失败重复供应。结果未知先核对既有对象与设备密钥，不覆盖、撤销或重建；管理 key 不分发给设备。
- 运行前重新核对目标主机、SSH 入口、服务身份及宿主 getAgentDir()；现场绝对路径只作部署证据，不成为运行时定位规则。密钥不进入 argv、临时明文、Git 或普通输出。
- run.py 的再次执行会创建新 run，不是上次结果未知时的恢复。只操作获授权的专用探针进程，不重置主力会话或中央服务。
- inbox 与消息均为合成数据；既有历史、正式设备身份、频道及测试消息不得擅自清理。损坏 inbox 不自动清空或跳过，未知状态不得以重新发请求掩盖。
- 探针的 ACK 故障窗口只核验原生传输和 REST 后备路径，不代表 SDK 内部崩溃、宿主通知恢复、正式连续游标或业务任务状态机已实现；缺字段的 P0 公告不得进入正式有效目录。
- 归档含现场定位信息；对外推送前另核对公开范围。npm 排除不等于 Git 不公开，既有本地归档授权不扩展为发布或生产部署授权。
