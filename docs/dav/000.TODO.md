# DAV 原生工具接入：任务与状态

## 说明

统一配置入口与邮件适配已完成并随 3.0.0 发布；本机邮件配置按独立授权迁移，旧文件保留，0600 权限、字段保真与默认发信身份经离线核验。本机安装与运行会话是否切换须独立确认。

用户随后显式配置 dav 账户并授权只读连接测试：本地 davkit 验证认证与集合发现，发现两个日历、四个地址簿，未读取日程／联系人正文或执行写入。这是独立库与服务入口证据，不代表原生插件工具已完成真实验收；不在仓库保存真实端点、账户凭据或返回数据。

本批用户授权继续原生 DAV 接入，范围为 davkit@0.1.0 可选依赖、DAV 配置工厂、10 个只读工具与离线验收。工具为 accounts、collections 和四类 list/get，不注册搜索／写入空壳。联系人搜索解码投影和写入兼容接口仍待独立库补齐或另行决策；不因此复制 parser、时间或重复算法。真实业务写入、发布安装、重载、旧服务停用均未包含在本批。

配置仍为宿主 getAgentDir()/tsgw.json 中的类型 → ID → 配置，顶层 imap/smtp/dav，ID 可跨组同名；核心与 provider 保留宿主入口。不增加独立 DAV 文件、逐项 type、defaultSmtp、命令取密码或环境变量展开。需求与依据见 [A00](A00.需求分析.md)、[B00](B00.规划设计.md)、[C00](C00.执行计划.md)。
