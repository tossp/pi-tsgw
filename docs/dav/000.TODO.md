## 说明

统一配置入口与邮件适配已完成离线验收：整套 npm test、生产编译、打包和文档检查通过，Astra/max 独立审阅无确证阻塞。本机邮件配置已按独立授权迁移，旧文件保留，字段保真、0600 权限和默认 SMTP 均经生产读取入口与 accounts 工具离线验证。未引入 DAV 依赖、访问真实服务或重载；发布、本机安装和运行切换分别报告。需求与实施依据见 [A00](A00.需求分析.md)、[B00](B00.规划设计.md)、[C00](C00.执行计划.md)。

已确认配置模型：Pi／Agent 核心与 provider 保留宿主入口，自定义扩展统一进入 tsgw.json，采用类型 → ID → 配置，顶层 imap/smtp/dav，ID 可跨组同名。不套 email、不逐项写 type、不保留 defaultSmtp；默认 SMTP 取组内首项。邮件工具始终 deferred 注册，调用才加载所需协议配置，缺配置返回本地指导。

用户已批准统一配置与邮件适配，并另行授权邮件配置迁移和源码发布；本机安装与重载不包含在发布授权内。DAV 条目字段、凭据读取范围、Node.js 24/可选依赖及编辑兼容契约留待 DAV 接入批次，不扩大本批实施。本专题不延续 docs/communication 的历史通信方案。
