# Magpie 扩展术语

本专题统一使用下列名称；需求、设计、执行计划和状态记录均沿用本表。

| 主叫法 | 定义与边界 |
| --- | --- |
| Magpie（喜鹊） | 当前网关实现。日常别称“麦克派”不作为文档主叫法。 |
| 网关身份 | 当前地址与宿主凭据作用域内，模型目录是否具有已确认的 Magpie 特征；不是不可变的服务身份认证。 |
| 功能能力 | 某个接口、字段或传输方式在当前实例是否可用；确认网关身份不代表全部能力可用。 |
| 厂商／产品族 | 额度分组层级，例如 OpenAI／Codex。渠道、远程网关和产品族不混称为厂商。 |
| 账户 | 上游订阅或余额所属的身份。同名账户可能经多个来源出现，不据此累计资源。 |
| 来源 | 当前网关或其转接的远程网关。保留协议中的完整来源标识。 |
| 卡片 | Magpie 保存的一条账户、套餐或余额记录；不是一个厂商的统一剩余百分比。 |
| 窗口 | 一项有独立周期、单位和读数的额度约束，例如滚动窗口、周窗口或积分池。 |
| 状态快照 | 插件最近取得的接口结果及获取时间、作用域和错误状态。 |
| 读数时间 | 网关记录该项上游数据的时间；与插件发出请求或取得快照的时间不同。 |
| 读取 | 查询网关已有缓存；本专题默认指不会为该请求主动刷新供应商的路径。 |
| 上游刷新 | 明确要求网关重新读取供应商额度；可能受节流影响而仍返回旧读数。 |
| 重置权益 | 可用于恢复额度的独立权益。消耗权益不等于读取或刷新。 |
| 真实会话 ID | 宿主 `sessionManager` 提供的会话标识，主会话和真实子会话各用自己的值。 |
| 辅助请求 ID | 没有独立宿主会话的搜索、选型请求的追踪标识；不冒充真实 Pi 子会话。 |
| 请求用途 | Magpie 的 `kind`／`purpose` 分类。文档中的“普通任务”是业务称呼，不是新的协议值 `task`。 |
| 父子关系 | 明确来源于宿主的上下级关系；普通分支会话不自动视为子代理。 |
| HTTP 请求头 | 请求 JSON 之外的传输字段，例如 `X-Magpie-Session`。 |
| 顶层请求元数据 | 请求 JSON 最外层的 `client_metadata`；不是 `messages[]` 或 `input[]` 中每条消息的属性。 |
| 已用比例／剩余比例 | 分别表达消耗与余量。网关状态原文按原义保留；底部摘要只由结构化窗口计算剩余比例。 |
| 厂商额度摘要 | 单账户共同限制窗口先取最低剩余比例，再取同厂商账户最大值；仅作快捷比较，不能相加为总资源或保证实际路由。 |
