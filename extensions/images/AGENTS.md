# 图片工具维护边界

本目录只维护图片工具、schema 与本地文件层；协议适配在 `extensions/models/adapter/images/`。参数、预算、默认值及调用方式以源码、测试和图片技能为准，不在这里重复。

- 接入范围固定为用户确认的 Flare 与 Sunburst 两款；新增型号、独立认证、上传服务或服务端改动均不在既有授权内。
- 用户已确认网关编辑端点兼容，这是接入前提，不是本插件完成真实验收的证据，也不授权重复付费探测。接口与模型依据见 Blinko 942。
- 默认值用于减少传参，不作为擅自缩减上游能力的理由；新参数仍须有适用于这两款模型的证据，不因共享 schema 或旧模型支持就开放。
- 原图及蒙版处理须保留原始字节，不把宿主预览当原图，不为了便利另建 URL 下载或上游 Files 上传链路。工具读取及外传依赖整体工具权限，不冒称内置 read 的审批或文件沙箱。
- 上游生成、文件保存、会话展示和最终交付分开报告；本地后处理失败不授权再次生成。消费流式响应不等于 Pi Web 支持渐进预览。
- 多图流式 usage 的逐图／累计归属未有明确契约，不猜测汇总、重复计费或因计量不明丢弃有效图片；改变归并方式前须取得证据。
- 修改协议或文件处理时，分别验证适配器与工具／宿主边界；合成图片和模拟 HTTP 不代替真实参数组合、图片质量或客户端展示验收。
