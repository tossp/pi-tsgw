# 创建前子代理选型

`index.ts` 在 Pi 1.2+ 接入兼容的 `model-only Agent`，`policy.ts` 承载固定问题、模型/思考档位候选和必要校验。主模型仍负责拆任务、权限、依赖、后台执行方式及验收；插件只补新建时的模型参数，不创建或管理子会话。

## 执行边界

- 只处理顶层 `Agent` 新建、没有非空 `model`、没有非空 `resume` 的调用。显式模型、续接、查询、steer、嵌套调用及子代理内部轮次不参与。`session_start` 通过公共 `getEntries()` 识别 Pi Web 的 `pi-web:subagent` custom 标记，子会话不注入用法或选型；普通 fork 的 `parentSession` 不作为角色证据。该标记是 Pi Web 宿主约定，不冒称适用于所有子代理宿主。
- 不新增工具，也不经 `ctx.executeTool` 嵌套调用 `Agent`。保留原调用 ID、任务提示词、档案、后台/隔离选项及宿主生命周期。
- 固定分类请求直接使用已有任务提示词和少量调用元数据；不发送会话历史，不读 `input_files` 内容，不要求主模型编写问题或代码。分类材料超过 28 KiB 时阻止自动创建，不截断原任务。
- 候选来自生效的 `tsgw` 聊天目录，并在配置了会话模型范围时进一步取交集；范围显式指定的思考档位同样限制候选。仅使用已维护的候选/档位，复用宿主支持档位判断。目录可用不等于端点健康。
- 分类器从生效的 `tsgw` 文本分类目录动态选择：已知非零输入＋输出参考价较低者优先，未知/零价排后，同价按 provider/ID 字典序确定；不按目录数组顺序、不固定模型 ID。价格用于确定性选择，不代表网关实扣价。
- 一次分类同时给出任务类型和候选选择。不按未经校准的置信度阈值、复杂度分数或 AA 分数自动映射档位；无法判断选择 `unresolved`。
- 正式架构/设计文档独立审阅只接受 Astra/max。固定 Kimi＋Astra 双审必须由主代理分别显式指定模型，不由一次分类发明额外子任务。自然语言类型判断仍是模型判断，不将其宣传成形式化安全保证。
- 分类与目录查询共享 15 秒取消窗口；无自动重试、无失败换模型。缺分类器、无候选、失败、未决、取消或选定模型已撤下时阻止本次自动创建，提示显式指定模型；不会静默使用父模型。分类成功后再次验证目录及档位。
- 原 `Agent` 的结果追加选型摘要，`details.tsgwDelegation` 记录分类器、目标模型、任务类型、耗时或安全错误原因；不保存原始分类响应、地址或凭据。已报告用量合入原工具 `usage`，不是重复计算子代理用量。
- 钩子原地修改参数后宿主不重新做 schema 验证，因此候选/档位由插件校验。后续钩子能看到选型后的参数并可阻止执行；更早的钩子不会自动重跑，不声称已经重做全部权限判断。
- 会话退出/重载中止本实例等待，迟到结果不能派遣；原 `Agent` 仍决定前台取消、后台任务和完成通知的语义。插件不让后台子代理随分类阶段的 signal 误停。
