# 子代理选型维护边界

候选知识在 `knowledge.ts`，过滤、选型材料及硬约束在 `policy.ts`，宿主集成在 `index.ts` 及相邻测试；调用说明在 `skills/tsgw-delegate-model-selection/SKILL.md`。不在规则中复制档位、价格、候选清单或分类流程。

- 技能与常驻注入只说明委派调用契约，不复制内部选型机制、候选表或失败接管步骤；接管指导仅在失败工具结果中按本次状态提供，使用已核验的有效候选，不要求另查模型目录。
- 主代理负责拆分、依赖、权限、并行和验收；分类只帮助选模型，不得借此新增子任务、复制宿主调度器或扩大原调用授权。
- 多候选用于任务匹配，不设普通任务的厂商／型号默认优先级，不按候选顺序形成能力阶梯；分类与失败接管共用本次有效候选，不用静态知识补回不可用项。
- 正式架构／设计文档独立审阅固定 Astra/max；Kimi＋Astra 双审由主代理显式分别安排，Kimi 不承担长程执行。局部检查不等于正式审阅，不因材料短或成本考量擅自降档。
- 用户授权创建前选型由原生分类与固定 Luna、DeepSeek Flash、MiniMax M3.1 Flash 聊天通道四路并行竞速，各请求一次，首个有效结果胜出；不采用投票，不为缺席通道补入其他型号，不推广为原生 `classify` 或其他付费能力的自动重试／换模型授权。复用各自已登记的宿主协议和厂商策略，不将 Responses 格式字段发送给 Anthropic Messages；各通道输出都须通过同一套本地候选与硬约束校验。先失败的通道只记录简短安全错误与 HTTP 状态码并继续等有效响应；工具输出同时展示胜出前已收到的通道错误，不回显上游正文，不把竞速取消的败路标为失败，不等待迟到诊断。全部无有效结果时沿用失败指导，由调用代理显式选型后重新派遣，不自动重跑。取消败路不保证远端停止处理或计费。
- 运行时复用宿主工具调用，不向分类器发送会话历史或读取 input_files 正文。Pi Web 的子会话标记是该宿主约定，不外推到所有 Pi 宿主，也不把普通 fork 当子代理证据。
- 工具钩子补参后宿主不会重新执行完整 schema／权限流程；插件须校验自己补入的候选和档位，不宣称更早的权限钩子已经重新运行。
- 模型换代遵循根 `AGENTS.md`：检查 `knowledge.ts` 与 `policy.ts`，默认由已确认的新版本接替同系列旧版本的选型与双审位置，清理旧推荐，不把保留旧聊天目录当作保留旧指导的理由。同步检查档位、价格、适用说明、分类提示、失败指导、测试及简短调用技能；保留旧版本须有具体依据，换代不放松审阅约束，执行任务的模型不必逐次查榜、探测后端或读取长表。
- 原 AA Intelligence Index v4.3.2 评分仅作历史参考，不是本地派遣质量的验证，不按未校准分数或置信度发明选型阈值。DeepSeek 1017 更新后的型号不沿用旧评分。
- 国内价格与背景资料入口为 Blinko 604（DeepSeek，2026-10-16）和 929（GLM）；价格及折算依据随厂商源码维护，不在本文件复制数值表。官方更新与评测不证明网关后端已同步，也不承诺本地通过率、耗时或任务总费用。
- 参考来源：DeepSeek 官方更新日志 `https://api-docs.deepseek.com/updates/`（2026-10-17）。其 DeepSWE 评测与 AA 不同口径，不直接比较。
- 新型号按上述规则加入选择器不等于长期工程能力已验收；任务适用性与参数须有依据，真实工具往返等未验证项应明确保留，不把最小文本验收推广为完整工程能力。
- 合成注册表、真实 SDK 加模拟 HTTP 仅验证边界逻辑；真实分类质量、子会话创建和 Pi Web 展示须分别验收，不能因隔离测试通过就声称已全部验证。
