# 子代理选型维护边界

实现与候选描述在 `index.ts`、`policy.ts` 及相邻测试，调用说明在 `skills/tsgw-delegate-model-selection/SKILL.md`。不在规则中复制档位、价格、候选清单或分类流程。

- 主代理负责拆分、依赖、权限、并行和验收；分类只帮助选模型，不得借此新增子任务、复制宿主调度器或扩大原调用授权。
- 正式架构／设计文档独立审阅固定 Astra/max；Kimi＋Astra 双审由主代理显式分别安排，Kimi 不承担长程执行。局部检查不等于正式审阅，不因材料短或成本考量擅自降档。
- 运行时复用宿主工具调用，不向分类器发送会话历史或读取 input_files 正文。Pi Web 的子会话标记是该宿主约定，不外推到所有 Pi 宿主，也不把普通 fork 当子代理证据。
- 工具钩子补参后宿主不会重新执行完整 schema／权限流程；插件须校验自己补入的候选和档位，不宣称更早的权限钩子已经重新运行。
- 更新目录、档位或选型依据时，检查策略和简短调用技能；执行任务的模型不必逐次查榜、探测后端或读取长表。
- 原 AA Intelligence Index v4.3.2 评分仅作历史参考，不是本地派遣质量的验证，不按未校准分数或置信度发明选型阈值。DeepSeek 1017 更新后的型号不沿用旧评分。
- 国内价格与背景资料入口为 Blinko 604（DeepSeek，2026-10-16）和 929（GLM）；价格及折算依据随厂商源码维护，不在本文件复制数值表。官方更新与评测不证明网关后端已同步，也不承诺本地通过率、耗时或任务总费用。
- 参考来源：DeepSeek 官方更新日志 `https://api-docs.deepseek.com/updates/`（2026-10-17）。其 DeepSWE 评测与 AA 不同口径，不直接比较。
- 新型号登记不等于长期工程候选资格；加入自动候选前需确认工具往返、任务适用性及依据，不把最小文本验收推广为完整工程能力。
- 合成注册表、真实 SDK 加模拟 HTTP 仅验证边界逻辑；真实分类质量、子会话创建和 Pi Web 展示须分别验收，不能因隔离测试通过就声称已全部验证。
