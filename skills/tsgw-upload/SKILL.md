# 本地文件上传

通过 codemode 按需发现 `tsgw_upload` 命名空间：先用 `describeNamespace("tsgw_upload")` 查看能力，再用 `describeTool("tsgw_upload_local_file")` 读取当前参数与结果说明，随后调用 `tools.tsgw_upload_local_file(...)`。不预加载或复制整套 schema。

## 调用前

- 确认具体文件及外传授权。路径位于 Pi 运行主机，不是浏览器所在机器；能读取文件不等于获准上传。
- 只使用宿主已连接并授权的 `ts_oht`；工具不可用时报告条件不足，不创建连接、寻找凭据或改配置。
- 按用户意图选择在线展示或附件下载，并核对链接有效期；链接有效期不会延长对象保留期。

## 结果与恢复

- 分别检查上传和链接状态：正常完成须有 `uploaded: true`、`linkStatus: ready` 和返回链接；仅拿到 key 或恢复凭条不代表已完成。
- 若已上传但获取链接失败，不重新上传文件；保留返回的 key、恢复凭条及可用 fallback，说明实际完成范围。
- 失败、取消或结果未知时，不自动重试、补偿上传或新建对象。只有用户明确要求恢复时，才原样使用上次返回的 `resume`；恢复前停止其他客户端对同一文件的上传。本地取消不保证远端已停止。
- 下载 URL 是持有者凭据，只向获授权的接收方交付，不写入仓库、笔记或普通日志，也不输出恢复凭条到普通日志。inline HTML 等活动内容可能执行，不能因私有存储就视为安全内容。
