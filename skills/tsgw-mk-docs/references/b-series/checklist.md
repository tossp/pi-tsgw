# B00.规划设计.md 复核清单

## 必查项

- 是否写清楚模块职责，以及每个关键模块不负责什么。
- 是否定义了接口契约、关键输入输出和边界条件。
- 是否记录了关键决策、取舍理由和被放弃方案。
- 是否把非功能需求映射到具体架构策略，而不是停留在口号。
- 是否能从 `A00` 需求追踪到 `B00` 模块 / 接口，再追踪到 `C00` 落地入口。

## 串层检查

- 是否混入 `C00` 的逐文件改动清单、命令、迁移任务或验证流水账。
- 是否把 TODO 状态、阻塞、完成度写成了设计正文。
- 是否把需求新增或验收标准修改偷偷放进了 B 文档。

## 结果检查

- 文档是否足以支撑后续实现者在不猜测总体结构的前提下进入 `C00`。
- 架构说明是否既有边界，也有理由，而不是只给结论不说明依据。
