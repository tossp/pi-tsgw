# A00.需求分析.md 复核清单

## 必查项

- 是否为每条需求分配了稳定需求 ID。
- 是否为每条需求写了验收标准或至少一个可验证场景。
- 是否把功能需求和非功能需求分开表达。
- 是否明确列出约束、假设、依赖和非目标。
- 是否给出了后续追踪指针，能映射到 `B00` 模块 / 接口与 `C00` 验证入口。

## 串层检查

- 是否混入 `B00` 的模块拆分、接口协议细节、数据模型口径。
- 是否混入 `C00` 的代码落点、命令、迁移步骤或发布细节。
- 是否把实施状态、勾选项或阻塞说明写成了需求正文。

## 结果检查

- 文档是否能单独回答为什么做、要做什么、做到什么算完成。
- 需求是否可被后续设计与测试验证，而不是停留在抽象口号。
