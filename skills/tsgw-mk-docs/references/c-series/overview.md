# C00.执行计划/详细设计.md 总览

## 职责

- 回答代码怎么落、怎么迁移、怎么测、怎么发。
- 把 `B00.规划设计.md` 的边界转换成可执行的代码、配置、验证和发布方案。
- 让实施、联调、回滚和验收都能沿文档找到入口。

## 边界

- 不新增需求，不改写完成标准。
- 不推翻 `B00` 已定架构；若边界不成立，应先回到 `B00` 补决策。
- 不用任务状态、勾选项或流水账替代详细设计正文。

## 写法口径

- 轻量写法可参考 OpenSpec tasks：按可验证步骤组织执行计划，而不是写成散乱备注。
- 中大型项目可参考常见 GB 详细设计口径，但只保留当前实现真正需要的模块说明。
- 模块裁剪见 [模块裁剪](modules.md)，交付前复核见 [复核清单](checklist.md)。

## 最小结论

- 至少给出执行入口、依赖顺序、主要代码落点和验证入口。
