# 子代理派遣

主代理负责拆分任务，提供目标、必要事实、文件路径、约束和验收标准；判断依赖、并行方式、权限和验收。委派描述应说明实际输入与工具条件、关键不确定性及结果如何验证；步骤清晰不等于问题简单。分类器不读取文件正文或图片，应在提示词中概括已查证的选型相关事实，不为选型复制整段材料或敏感内容。输入未齐备时先查证，不用分类代替授权或依赖验证。

## 调用

- 当前 PiWeb 将 `Agent`、`get_subagent_result`、`steer_subagent` 注册为 `model-only`，三者只能由主模型直接调用，不得放入 codemode 或其他工具包装器；`tools.get_subagent_result(...)` 等写法无效。出现工具不存在错误时，不猜名称、不重复搜索或重试嵌套调用。独立派遣可在同一回复中发起多个直接 `Agent` 调用。
- 新建子代理：直接调用宿主 `Agent`，填写 `prompt`、`description`、适合的 `subagent_type` 和执行选项。没有明确模型要求时省略 `model`；插件在创建前完成一次分类选型并补入模型和思考档位，原 `Agent` 随即执行。
- 独立任务优先 `run_in_background: true`；前置依赖未完成或存在并发修改冲突时不要假装独立。不要重复派遣已在执行的任务。
- 后台任务完成后，当前 PiWeb 会在主会话空闲时发送结果通知并触发后续处理。派出后继续推进独立工作；没有独立工作时结束当前轮次，等待通知，不反复查询、不习惯性调用 `get_subagent_result({ wait: true })` 占用前台。只有查看中间状态、排障或明确需要同步取结果时才主动查询；通知尚未到达不代表任务未完成，不因此重复派遣。
- 用户指定模型、项目固定模型或审阅组合时，直接显式传入 `model`（`provider/modelId:level`），跳过分类。正式架构/设计文档独立审阅默认 `tsgw/gpt-6-astra:max`；固定双模型审阅分别使用 `tsgw/kimi-k3.1-pro:high` 与 `tsgw/gpt-6-astra:max`，不能把一份双审任务交给一次自动选择。
- 自动选型只适用于创建子代理且未指定 `model`；续接已有会话时传 `resume`，不传新模型，即使续接调用没有 `model` 也不再选型。直接调用 `get_subagent_result` 查询结果、`steer_subagent` 补充指令及子代理后续轮次均不触发分类，也不运行中换模型。
- 原生分类请求失败时，插件固定通过已可用的 `tsgw/gpt-6-luna` 聊天通道兜底一次，以严格 JSON Schema 限定类别与当前候选枚举，只回答同一组选型问题，不生成解释或执行任务；不重试原分类器、不轮换其他模型。Luna 作为分类执行器，不受子代理候选的会话模型范围限制，但必须在宿主可用目录中。Luna 不可用或兜底仍失败时，保留原分类失败返回。正常返回的未决／非法结果不触发兜底，选定模型失效时也不改选。
- 最终选型失败、结果未决或选定模型失效时，本次自动创建被阻止。工具返回具体失败类型和同源选型建议表；发起调用的主代理按指导自行选择当前可用模型，显式指定 `Agent.model` 后重新派遣，不重试分类器或自动更换分类模型。建议表只列本次按宿主可用目录、会话范围和合法档位过滤后的有效候选，与分类材料同源；无候选或核验未完成时只说明原因，不展示静态全表。用户指定和固定审阅要求优先。
- 原生分类与 Luna 兜底共用 15 秒选型上限；总预算耗尽、调用取消或会话结束不再启动兜底。超时只阻止本次自动创建，不暂停后续独立调用的自动选型。调用取消或会话结束不视为超时，不自动重新派遣。

选型结果、明确的选型来源（分类模型或聊天模型及其 ID）、原分类器、实际调用的兜底模型及两次请求已报告的累计用量附在原 `Agent` 的工具结果中；失败时注明未完成有效选型，不把尝试记录当作选择来源。无需编写 codemode 脚本，也不需要先询问分类器再组织第二次 `Agent` 调用。

自动选型不修改任务提示词、档案、后台标志、隔离选项、宿主权限或调度规则。没有兼容宿主工具或低版本 Pi 时不挂接自动选型；需按宿主实际能力显式选择模型，不将技能提示当作已加载运行时代码。

固定选型知识及维护边界位于插件的 `extensions/delegation/`，由插件维护，不要求执行任务的主模型查榜、探测型号或读取完整参考资料。候选知识、硬约束和运行时有效候选分开维护；普通任务不设厂商或型号默认优先级，候选顺序不是排名。依据任务与各候选的适用条件、局限和参考成本选择模型及档位；复杂任务不一律使用最高档，不把跨模型档位当作等效能力。分类会增加请求延迟与费用，触发 Luna 兜底时最多再增加一次请求；官方定位及隔离回归均不证明实际选型质量、耗时或任务总费用已改善。
